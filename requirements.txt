# Install with:
#     python -m pip install -r requirements.txt

# Notes on the pinning strategy
# -----------------------------
# The HEEM code targets the Qiskit 0.x API. It imports modules that have been
# removed in Qiskit 1.0+ (qiskit.opflow, qiskit.providers.ibmq,
# qiskit.algorithms.optimizers) and uses the qiskit_nature.*.second_quantization
# namespace that was removed in qiskit-nature 0.7. The pins below therefore
# stay on the last patched release of the Qiskit 0.x line:
#
#   - qiskit-terra 0.46.3 includes the fix for CVE-2025-2000 (the critical
#     QPY deserialization RCE) while preserving the legacy API.
#   - qiskit-nature 0.6.2 is the last release that still exposes the
#     `second_quantization` submodule used throughout this codebase.
#
# All non-Qiskit dependencies are bumped to a patched version that closes
# every advisory previously reported on this repository.
